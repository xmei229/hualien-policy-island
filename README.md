# 花蓮縣長 2026・政見島

把花蓮縣長選舉三位候選人（魏嘉賢、張峻、游淑貞）公開發表的政見與主張，整理成可互動的 3D 小島網頁。

## 編者說明
- 整理者：FB `xmei.wang`（https://www.facebook.com/xmei.wang）
- 整理者與任何候選人、政黨、競選團隊無關係，未收受任何金錢或贊助。
- 純粹分享蒐集到的公開資訊，不含編者個人意見。

## 資料原則
- **政見**＝候選人整合發布的文件或網站；**主張**＝零散貼文或報導中的表態。
- 每一則要點都附出處與原文引句，可在頁面上點開查證；「已確認」只代表候選人自己說過，不代表可行或屬實。
- 資料截止日顯示於頁面上方。

## 更正
發現錯誤、缺漏或過時，請到上方 FB 私訊或留言，附上出處連結，查證後更正。

## 檔案
- `index.html`：整個網站（單一檔案，資料與貼圖已內嵌，無需後端）
- `data/`：頁面所用的原始資料（出處、引句、島與要點等，JSON）
- `textures/CREDITS.md`：貼圖來源與授權（CC0）
